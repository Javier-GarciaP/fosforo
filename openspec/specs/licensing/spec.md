# licensing Specification

## Purpose
Declara bajo qué licencia se distribuye el proyecto.

## Requirements

### Requirement: MIT license
The repository SHALL include a `LICENSE` file with the MIT license text at its root, and the README MUST state the license.

#### Scenario: Licencia visible
- **WHEN** una persona abre el repositorio en GitHub
- **THEN** GitHub reconoce la licencia MIT y el README la menciona
