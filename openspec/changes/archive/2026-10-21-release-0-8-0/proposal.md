# Proposal

## Why

Todos los cambios del plan están implementados y probados en `dev`. Antes de publicar la primera versión (`0.8.0`) la documentación debe reflejar el estado real:
hoja de ruta marcada, instrucciones de instalación con una línea de comandos y el CHANGELOG fechado.

## What Changes

- README y `docs/README.md`: estado `0.8.0`, hoja de ruta marcada, instalación (`curl | sh`, `go install`, descarga manual), actualizar y desinstalar, y sección «Cómo se construyó».
- CHANGELOG: entrada `0.8.0` fechada (de ahí salen las notas de la release).

### Modified Capabilities

Ninguna.

## Non-goals

- Homebrew y npm (requieren un repositorio de tap, tokens y, en npm, un nombre distinto de `fos`, que ya está ocupado): se valorarán más adelante.
